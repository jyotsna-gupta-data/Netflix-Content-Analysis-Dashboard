# 🎬 Netflix Content Analysis Dashboard

An interactive Power BI dashboard tracking Netflix's global movie and TV show library, rating trends, genres, and overall growth.

---

## 📊 Key Highlights & Insights

* **Total Content Library:** Analyzed 8,807 total titles, made up of Movies (69.6%) and TV Shows (30.4%).
* **Top Countries:** The United States produces the most content, followed by India and the United Kingdom.
* **Main Target Audience:** TV-MA is the top content rating, showing a strong focus on mature audiences.
* **Fastest Growth Period:** Content uploads increased rapidly after 2015, reaching a peak in 2019.

---

## 🛠️ Tools Used
* **Power BI:** Built interactive charts, created calculated measures, and designed the main dashboard layout.
* **Excel / MySQL:** Cleaned messy data and ran queries to explore the dataset.
* **Canva:** Designed background layouts and graphics to make the dashboard look clean and modern.
